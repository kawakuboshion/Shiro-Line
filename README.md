# 🌌 SHIRO-LINE（シロ・ライン）

> **「白（シロ）」から始まり、「白」へと還る、光と色彩のミニマル・デジタル迷宮。**
> 
> 『SHIRO-LINE』は、光の三原色（赤・青・緑）の「足し算（混色）」と「引き算」の性質を利用してステージを攻略する、新感覚の2D無重力アクションパズルゲームです。

---

## 🎮 ゲーム概要

かつて世界は、すべての色を含んだ美しい純白の光「シロ」に満たされていた。
しかし、突如現れた「カラフルな混沌（ボイド）」によって色たちがバラバラに分離し、世界は動きを止めてしまう。
プレイヤーは純白の光の結晶「シロ」を操作し、ステージに散らばる光を回収・合成しながら、世界を再び調和ある「しろ（白）」にリセットするための旅に出る。

---

## ✨ 主な特徴（ゲームシステム）

### 1. 無重力・慣性スワイプアクション
一般的な2Dゲームのような「重力」はありません。宇宙空間を漂うように、ドラッグ（スマホならスワイプ）した方向へ滑らかに慣性移動します。プレイヤーが動いた後ろには、まばゆく輝く「光の軌跡（ライン）」が美しく描かれます。

### 2. 光の三原色システム（色の変化と相性）
ステージ内の「カラーインク」に触れることで、プレイヤーの体色、2Dライト、光の軌跡が一斉に変化します。

*   **【白（シロ）】**：初期状態。すべての色の壁を無条件ですり抜けることができる。
*   **【赤・青・緑】**：同じ色のレーザー障壁（壁）をすり抜けることができるが、異なる色の壁には激しく弾かれる。
*   **【黒（シャドウ）】**：光を吸収するトゲやブラックホール。何色の状態であっても、触れた瞬間にまばゆい光の粒子となって**爆発四散（即ゲームオーバー）**し、ステージの最初からリトライとなる。

### 3. 三原色の合成（混色パズル）
色を保持したまま次のインクに触れることで、色が足し算されます。
*   `赤` ＋ `青` ＝ **【紫（マゼンタ）】** ➡ 赤と青、両方の壁をすり抜ける
*   `赤` ＋ `緑` ＝ **【黄（イエロー）】** ➡ 赤と緑、両方の壁をすり抜ける
*   3色が揃う、または「白インク」を吸うことで最初の【白】へ回帰する。

### 4. 光学ギミック：プリズム・ミラー（鏡）
プレイヤー自身が「光線（レーザー）」に変身して大砲から超高速で弾け飛び、ステージに配置された45度の鏡（ミラー）に衝突することで**直角に折れ曲がって進む**、光の性質そのものを活かした知的なパズル。

### 5. 無重力ならではの「動く盾」リフト
カラー・エンジン（スイッチ）を起動することで動くリフトは、単なる足場ではなく、敷き詰まった**黒いトゲ（シャドウ）から身を守るための「物理的な防護壁」**として機能します。リフトの影に隠れながら全方向移動でついていく緊張感を味わえます。

## 🎨 ビジュアル ＆ サウンドスタイル

*   **ネオン・サイバーグラフィック**：URP（Universal Render Pipeline）の2D Lightとポストプロセス（Bloom）を最大限に活かし、真っ黒な背景に対して鮮やかなネオンカラーが美しく映えるミニマルな世界観。
*   **インタラクティブな電子サウンド**：移動、インク回収、壁のすり抜け、そして死亡時の大爆発に至るまで、プレイヤーの行動に合わせてシンセサイザーの透明感あるエフェクト音が響き渡り、ゲームへの没入感を高めます。

## 🛠 開発環境と主要技術

*   **ゲームエンジン**: Unity 6000.3.10f1 (Universal2D)
*   **グラフィックス**: Universal Render Pipeline (URP) 2D
    *   `Global Volume` / `Bloom` (ネオン発光演出)
    *   `2D Light` (プレイヤーやオブジェクトの動的発光)
*   **物理・移動**: `Rigidbody2D` / `Physics2D.IgnoreCollision` (色による動的なすり抜け判定)
*   **視覚エフェクト**: `Particle System` (吸い込まれるゴールエフェクト、ダイナミックな死亡爆発) / `Trail Renderer` (光の軌跡)
*   **UI・フォント**: `TextMesh Pro` (アウトラインとGlowを効かせたネオン文字UI)
